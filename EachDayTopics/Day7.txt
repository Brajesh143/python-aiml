System Design Practice — 20 min:
==================================

    Scenario:
    ----------

        You need to design an e-commerce application supporting:

        100,000 requests/minute

    Features:
    ----------

        User Login
        Product Search
        Product Details
        Order Creation
        Payment
        Email
        Notifications
        Analytics


    Start with:
    -------------

                       Client
                          ↓
                         DNS
                          ↓
                   Load Balancer
                          ↓
             ┌────────────┼────────────┐
             ↓            ↓            ↓
          Server       Server       Server
             │            │            │
             └────────────┼────────────┘
                          ↓
                        Redis
                          ↓
                       Database
                          ↓
                    Message Queue
                    /     |      \
                 Email  Notify  Analytics

    
    Now explain:
    -------------

        Q1: Why do you need a Load Balancer?

        Q2: Why should your Node.js servers be stateless?

        Q3: Where would Redis help?

        Q4: Which operations should go through the Message Queue?

        Q5: What happens if one server crashes?

        Q6: What happens if Redis crashes?

        Q7: What happens if the database becomes the bottleneck?

        Q8: How would you handle 100,000 requests/minute?
